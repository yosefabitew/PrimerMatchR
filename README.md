# PrimerMatchR

PrimerMatchR is an R package designed to verify primer binding sites on plasmid sequences and automatically generate a visual, color-coded report. It identifies both forward and reverse complement binding sites and renders them into high-quality HTML and PDF outputs.

## Installation

You can install the development version of PrimerMatchR directly from GitHub:

```r
# Install remotes if you haven't already
install.packages("remotes")

# Install PrimerMatchR
remotes::install_github("your-username/PrimerMatchR")
